# 경력기술서 유지보수 안내

이 폴더는 `이창엽_경력기술서`의 향후 수정, 업데이트, PDF 재생성을 위한 관리용 작업 폴더입니다.

## 폴더 역할

- `updater/`: 이후 내용을 수정하고 PDF를 다시 생성할 때 사용하는 관리용 폴더
- `final/`: 제출 직전 또는 제출 완료 기준의 보관용 폴더

작업을 다시 시작할 때는 먼저 `updater/이창엽_경력기술서.tex`를 수정하고, PDF를 새로 생성한 뒤 검토가 끝난 버전을 `final/`에 반영하는 흐름을 권장합니다.

## 현재 파일

```text
updater/
├── README.md
├── 이창엽_경력기술서.tex
└── 이창엽_경력기술서.pdf
```

### `이창엽_경력기술서.tex`

경력기술서의 LaTeX 원본입니다. 문구, 섹션, 활동 내역, 날짜, 수상, 자격, 프로젝트 내용을 수정할 때 이 파일을 편집합니다.

### `이창엽_경력기술서.pdf`

현재 LaTeX 원본을 기반으로 생성된 PDF입니다. 제출 전에는 반드시 PDF를 열어 레이아웃, 줄바꿈, 페이지 수, 한글 표시, 링크 표시를 확인해야 합니다.

## 유지보수 기본 흐름

1. `updater/이창엽_경력기술서.tex` 수정
2. LaTeX 컴파일로 PDF 재생성
3. 생성된 PDF 육안 검토
4. 필요 시 문구, 줄바꿈, 여백, 항목 순서 재조정
5. 최종 확인 후 `final/` 폴더에 `.tex`와 `.pdf` 복사

## PDF 재생성 예시

`naver_work/updater` 폴더에서 아래 명령을 실행합니다.

```bash
tectonic 이창엽_경력기술서.tex
```

컴파일이 완료되면 같은 폴더에 아래 파일이 갱신됩니다.

```text
이창엽_경력기술서.pdf
```

## 최종본 반영 예시

`updater`에서 PDF 검토가 끝난 뒤, 제출용 보관본을 갱신할 때 사용합니다.

```bash
cp naver_work/updater/이창엽_경력기술서.tex naver_work/final/이창엽_경력기술서.tex
cp naver_work/updater/이창엽_경력기술서.pdf naver_work/final/이창엽_경력기술서.pdf
```

## 수정 시 우선 확인할 항목

- 최신 활동이 위에 배치되어 있는지 확인
- 지원 직무와 직접 관련 있는 경험이 앞쪽에 드러나는지 확인
- 날짜 형식이 문서 전체에서 일관적인지 확인
- 현재 진행 중인 활동은 `현재` 또는 명확한 종료 예정일로 표기
- 제출처에 따라 과도하게 내부적인 표현이나 불필요한 세부사항은 제거
- PDF에서 한 줄이 어색하게 넘치거나 페이지 하단에 단독 항목이 남지 않는지 확인

## 내용 업데이트 기준

새로운 활동이나 수상 이력이 생기면 아래 순서로 반영하는 것을 권장합니다.

1. `요약`에 반영할 가치가 있는 핵심 변화인지 판단
2. `주요 경험` 또는 `핵심 프로젝트 및 활동` 중 적절한 섹션에 추가
3. `수상 및 성과`, `발표 및 논문`, `자격 및 취득 이력`에 해당하는 항목이 있으면 최신순으로 추가
4. PDF 컴파일 후 전체 페이지 흐름 확인

## 문장 작성 기준

경력기술서 본문은 수치가 없는 버전에서도 활동 내용과 역량이 명확히 보이도록 작성합니다.

권장 표현:

- `담당했습니다`
- `수행했습니다`
- `정리했습니다`
- `분석했습니다`
- `구조화했습니다`
- `개선했습니다`
- `기여했습니다`

피하는 표현:

- 지나치게 모호한 표현: `열심히 했습니다`, `다양하게 경험했습니다`
- 검증이 어려운 과장 표현: `완벽히 해결했습니다`, `최고 수준으로 수행했습니다`
- 담당 범위가 불명확한 표현: `프로젝트를 성공시켰습니다`

## 제출 전 점검 체크리스트

- PDF 파일명이 제출용 이름과 일치하는지 확인
- PDF가 정상적으로 열리는지 확인
- 페이지 수가 과도하게 길지 않은지 확인
- 연락처, GitHub, LinkedIn, 블로그 링크가 최신인지 확인
- 학교, 기관, 프로젝트, 수상명 오탈자가 없는지 확인
- 현재 활동의 기간이 최신 상태인지 확인
- 지원 직무와 무관한 내용이 지나치게 앞에 배치되어 있지 않은지 확인

## 관리 메모

`updater`의 파일은 수정 가능한 작업본입니다. 제출이 확정된 버전은 반드시 `final/` 폴더에도 동일하게 복사해 두는 것을 권장합니다.
